# 问答全景：看清一轮 Agent 做了什么

新问答的回答或错误消息下方显示「本轮全景」。点击打开「问答全景」，沿连线查看实际节点、依赖、状态、耗时和工作摘要。生成期间也可打开实时记录。依赖图支持上游高亮、缩放、全图；节点列表便于窄屏阅读，方向键、Home/End 可切换节点，Escape 关闭并恢复焦点。从详情区跳往上游/下游或使用方向键、Home/End时，所选节点和键盘焦点会一同滚入弹窗可见范围；窄屏中列表在详情上方时也能看到跳转目标。

## 节点如何理解

| 节点 | 记录的事实 | 不代表什么 |
| --- | --- | --- |
| 请求与上下文 | 已受理的会话、Agent、配置、历史装配 | 不包含受理前 HTTP 校验与排队时长 |
| Skill / 知识 | 本轮实际选入的指引和检索来源 | 加载 Skill 不等于执行脚本，手册不等于实时数据 |
| MCP 目录 | 缓存目录或实际连接/发现的结果 | 发现工具不等于调用工具，不保证后续在线 |
| 模型 | 实际模型请求、轮次、用量与处理耗时 | 不显示内部推理，也不解释未记录的决策 |
| 工具 | 实际受治理的工具处理及结果状态 | 待审批尚未执行；完成不等于业务健康 |
| 委派 / 子 Agent | 模型实际分派、独立子任务、主子授权交集与处理分支 | 不代表扩大权限、继承全部父历史或允许递归 |
| 共享预算 | 实际模型轮次及 token/在途预算检查、通过或拒绝 | 不代表独立额外额度，不能把各分支耗时相加 |
| 结果回传 / 汇总 | 有界结构化返回、失败信息和交回主模型的依赖 | 汇总工具结果不等于已经生成最终答复 |
| 独立复核 | 通过、拦截、不可用或跳过 | 不替代人工审批，不能撤销既有查询 |
| 答复 | 对用户发布的结果类型 | 发布失败说明不表示任务成功 |

箭头表达本次处理的输入和先后依赖，不能据此断言模型引用了某条资料。点击节点可沿「依赖上游」「交给下游」继续查看。等待审批的历史图固定保留生成时状态，审批后的最新动作应在「执行与审批」核对。

每个模型节点的名称取自该次请求选用的配置快照；等待响应期间修改设置不会改写该节点。下一次分析或复核请求仍读取届时的配置，因此同一轮可能出现多个模型名。最终消息的 `metadata.model` 记录生成候选的最后一次分析模型，复核模型在自己的节点中查看。这里只证明请求中指定的模型名，不证明供应商内部实际路由。

## 存储、权限与导出

全景默认记录到新聊天与定时 Agent 任务产生的 `messages.metadata.executionTrace`，不依赖可选 `evidenceReports` 开关。复用会话 API 和所有者/管理员权限；全景交付时未新增迁移；当前 schema v7 的委派生命周期表和 v6 的任务目标列不改变既有图谱，也不回填旧消息；固定工具和 Runbook 不凭空生成 Agent 图谱。

快照 `version=1` 包含 `runId`、开始/结束 ISO 时间、`durationMs`、总状态、`nodes`、`edges`。新记录还包含 32 位十六进制 `traceId` 和 16 位 `spanId`；每个节点有自己的 `spanId` 与 `parentSpanId`。它们在实时事件、持久消息和回读中一致；旧记录可能没有这些字段。委派节点增加可选 `agentRunId`、`parentAgentRunId`、`parentNodeId`，分别标识所属 Agent 运行、父运行和委派包含关系；edges仍表示处理依赖，span父关系与数据依赖分别记录。主 Agent 与每个子 Agent在依赖图/列表分组，可直接定位分支、查看所属父节点和失败状态。节点包含稳定轮内 ID、kind、label、status、时间、summary，以及有界的 label/value 详情；边用 from/to 引用节点。总状态为 running/completed/awaiting_approval/error/cancelled/blocked，节点另有 skipped。NDJSON 新增 `{type:"trace",trace:...}`，不改变原有正文和终态事件。

记录不包含问题/提示原文、模型候选答案、工具参数/返回正文、凭据和私有推理；动态名称经现有脱敏函数及长度限制处理。图谱只展示当前用户实际授权上下文的资源信息。每轮最多 200 个节点、400 条边；达到上限时记录 omittedNodes/omittedEdges，入口标记「部分记录」，弹窗提示实际省略数量，分组与依赖仅覆盖已记录部分；每节点最多 8 项详情，身份值最多 240 字符。Skill 前 32 项逐项展示，剩余聚合；知识沿用最多 5 片段限制，避免无界遥测。

「导出 JSON」在浏览器本地下载上述快照，不发外部请求。导出是消息生成时点的记录，不能当作后续审批状态或持续业务健康证明。

## 可靠性边界

实时图是暂态观测，最终从持久会话回读。浏览器断开不会自动重放工具；请在会话或执行中心核对。没有持久图谱的旧消息不根据文本补造。进程硬退出、磁盘故障或进入引擎前的拒绝可能没有消息快照；持久执行台账仍是排查入口。

图谱时间使用服务端时钟，记录模型/工具与整体可观测耗时；并行或包含关系不能简单相加。`/metrics` 从实际完成的图谱聚合 run/model/tool/mcp/review/delegation/subagent/handoff/aggregate/budget 耗时直方图与固定结果计数，数据只在当前进程内存中，重启清零，无法代表多实例汇总。可选 OTLP/HTTP JSON 出口在部署显式配置后发送同一 trace/span ID 的固定阶段、状态和时间；另一个显式开关可向本轮模型和 MCP 请求发送 W3C `traceparent`。默认两者关闭，不接收或信任入站 trace 上下文，也不证明远端真的继续传播。采样、出口、故障和有界队列见 [AgentScope 运行指南](agentscope-runtime.md)。现有 `aiops_model_cost_total` 是按配置单价计算的估算值，不是供应商账单。仍未实现完整审批生命周期图或全量输入输出回放。下一步优先级见 [Agent 使用与开发](agent-development.md)，本轮证据见 [验证记录](verification.md)。

## 使用现有模型与真实 DTS 验收

显式真实验收入口会请求当前保存的模型并产生用量。DTS 阶段使用现有已授权的只读 MCP，需先接通公司网络；选择已经获准且仍可访问的任务 ID，不枚举目标或扩大区域权限。

```sh
npm run build
npm run test:panorama:real -- --phase knowledge
npm run test:panorama:real -- --phase dts --job 12345678901234567
# 两个阶段一起运行：
npm run test:panorama:real -- --phase all --job 12345678901234567
```

脚本以只读方式读取当前工作空间配置，在独立临时数据库和可见 Chrome 完成流程，结束时清理临时实例。模型/MCP 凭据只在内存解密并以临时密钥重加密，不打印或写入报告；调度关闭，不修改原账号、资源与模型设置。报告核对起止源码摘要、原配置摘要、真实 HTTP 模型请求、工具台账、DTS 返回、图谱导出与持久回看。

知识阶段走入门模板的编辑、下载、ZIP 上传、发布、绑定和真实模型问答。静态知识是专用验收材料，不冒充实际业务系统资料。DTS 阶段核对真实状态查询、独立复核和越界请求；每轮失败原样记录，不用自动重试把失败覆盖成成功。截图与报告保存在按时间分开的 `test-results/panorama-real-*`。

通过这些场景只能证明该候选的专项链路；不能替代完整质量语料、人工评分、持续负载、镜像安全或生产上线验收。

自主委派的单层只读限制、子任务输入输出、持久化与参考实现见[自主委派](agent-delegation.md)。
