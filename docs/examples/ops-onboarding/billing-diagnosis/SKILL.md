# 计费只读排障流程

## 输入

确认服务名、环境和问题。缺少必要参数时先询问，不猜测目标。

## 工作步骤

1. 阅读本轮提供的相关知识片段，提取阈值和适用条件；未提供就说明依据缺失。
2. 用户要求当前状态时，调用已授权的 service_status，明确传入 service 和 environment。
3. 工具不可用、失败或没有返回时，写明“未取得实时数据”，不能复用历史值冒充新查询。
4. 若返回 fixture=true，明确写“教学模拟数据”，不能描述成生产实际故障。
5. 比较同单位的指标与手册阈值，列出差值。没有阈值时不编造。
6. 将已观察事实与可能原因分开。缺少证据时给出下一步检查建议。
7. 不执行重启、删除、扩容或任何写操作。

## 输出格式

固定使用四个部分：观察事实 / 阈值对照 / 排查建议 / 来源与缺口。
在来源与缺口中标注知识名称、工具名、采样时间；缺少哪项就明确说明。
