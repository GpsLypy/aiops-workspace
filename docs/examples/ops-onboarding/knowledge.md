# billing-lab 计费超时手册（教学数据）

适用对象：服务 billing-lab，环境 test。文档版本 lab-1.0。
本手册只用于入门练习，阈值不代表任何真实系统的生产标准。

## 判定依据

- P95 响应耗时阈值：800 ms；超过阈值需要排查。
- 数据库连接池等待数阈值：20；超过阈值需要排查。
- P95 表示在统计窗口内，95% 的请求耗时不超过该值。
- 必须注明采样时间与统计窗口；缺少时标记为未知。
- 知识核验码：KB-LOTUS-2048。仅用于证明本练习资料被读取。

## 排查顺序

1. 确认服务、环境和故障时间。
2. 查询服务状态，检查 P95 和连接池等待数。
3. 若超标，继续检查数据库慢查询、连接占用、下游耗时和近期发布。
4. 指标超标只能证明存在异常信号，不能单凭它确认数据库是根因。
5. 缺少日志或依赖指标时列出证据缺口，不自动重启、扩容或修改配置。
