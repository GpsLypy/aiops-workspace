# 文档中心：查看和维护项目用户文档

左侧 **AgentScope 入门正下方 → 文档中心** 是独立菜单，地址为 `#documents`。登录后可直接打开 [本机文档中心](http://localhost:5173/#documents)。首页以搜索、阅读入口和分类文档卡片展示项目手册；卡片包含标题、原文摘要和路径。点击卡片进入阅读页，地址带 `file` 参数，刷新保留选择；文档中的相对 Markdown 链接可跳到已收录文档，浏览器前进/后退可在首页和已打开的文档之间切换。

首页的「入门与使用」「代码库与开发」「部署与运维」按实际收录分类显示，点击后筛选相应文档。搜索覆盖标题、路径和正文，与分类同时生效；「查看全部」清除筛选，搜索框右侧可清空关键词。文档和分类数量来自当前部署目录，不添加稳定性或发布状态等推断标签。

阅读页顶部可返回 **全部文档**。左侧目录按分类折叠，默认展开当前文档所在分类；列表只显示标题，完整路径在阅读工具栏和目录项悬停提示中显示。宽屏右侧的 **本页目录** 来自正文二、三级标题，可点击定位并聚焦章节。320px窄屏优先显示正文，通过 **文档目录** 按钮展开或收起目录；卡片单列排列，代码和表格在正文内滚动。

首页与阅读页顶部的 **架构图** 在新标签页打开 `/architecture.html`，可切换系统架构与请求流程。系统图支持分区、聚焦、搜索和缩放；请求图用编号主线、菱形判断和工具回路解释先后顺序，提供直接回答、查数据和发起修改三个逐步示例。两图均支持主题和图形导出；请求图手机端展开步骤，自动演示到待审批处暂停；文档中的相对架构图链接也会打开此入口，原稿和编辑状态保留。动效展示源码中的结构与流向，不连接真实会话；系统架构包含调度器等通用能力，不代表当前沙箱启用了这些后台服务。

## 收录范围

代码库速览提供 src/ 前端、server/ 后端、agent-worker/ Python 编排的直接入口，「查看全部目录」打开 [代码库与目录说明](repository-guide.md)。常用分类在前，学习、历史验证与教学附件在后。

读取当前部署目录中的项目 `README.md`、`docs/` 用户手册和教学附件，以及 `deploy/`、`integrations/` 中的 Markdown 说明、交接与示例。包括本文、验证记录、部署教程、DTS 说明和离线网站维护说明。章节目录明确登记的根、前端、组件、后端、运行时、Worker 和脚本源码地图也支持阅读与维护；未登记的 codemap.md 不自动收录。新增符合范围的 Markdown 后，点击刷新即可收录。

未在章节目录中登记的源码地图、开发代理规则、OpenSpec 材料、配置/凭据、业务数据库、测试报告和生成的 HTML 不作为用户文档展示。隐藏目录、依赖、构建目录及符号链接不收录。`docs/site/README.md` 是维护说明，单独收录；生成的 `docs/site/index.html` 由构建维护。

文档中心与知识库资源分开管理。编辑手册不会自动创建或更新知识库、Skill/MCP 资源，不触发聊天、模型或工具执行。Markdown 经过 HTML 清理，代码块仅供阅读，Mermaid 图源显示为代码。独立架构图链接打开图形查看器；其他源码、图示等配套链接会提示项目路径，可在本机目录查看。

## 阅读、修改和保存

1. 在首页搜索、筛选并打开文档卡片，或在阅读页目录中切换文档。
2. 普通成员可阅读和下载；管理员点击 **编辑文档**，修改 Markdown 原稿，可切换原稿、原稿与预览、预览。
3. 点击 **保存修改**。服务器检查内容摘要版本，保存原文件、重建离线网站并检查生成结果；全部成功才提示「已保存，离线文档网站已同步更新」。
4. 刷新页面核对正文仍保留。离线网站由同一次保存更新，无需手工修改 HTML。

保存期间原稿只读，不能切换文档、返回首页或离开文档中心。存在未保存修改时，返回全部文档、换文档、浏览器前进/后退、导航、退出编辑、刷新当前文档和退出登录会询问是否放弃；取消后保留编辑原稿和当前文档。刷新/关闭浏览器使用浏览器离开提醒。草稿仅在页面内存中，确认放弃或会话过期后不保证保留，必要时先下载草稿。

## 保存失败时

| 提示 | 处理方法 |
| --- | --- |
| 文档已被其他人修改 | 下载保留的草稿，重新加载最新文档，合并再保存；系统不会覆盖其他版本 |
| 目录不可写或网站构建检查失败 | 本次写入回退，草稿保留；检查新增 Markdown 链接目标、文档和网站目录写权限，修正后重试 |
| 回退未完成 | 下载草稿，由部署管理员检查原文与网站；不要把失败当作已经保存 |
| 文档不存在或目录为空 | 重新加载目录；确认部署包包含用户文档源文件 |

单篇上限 **512 KiB**。单实例保存串行执行，以摘要检测过期版本；终端或外部编辑器仍需避免在保存/重建窗口同时修改相同文件。页面不提供新增、删除、任意路径读取或执行文档指令。

## 部署与权限

完整源码工作空间支持上述文档的浏览和维护。精简公司沙箱源码包、既有容器镜像可能没有 `docs/` 等目录：应用仍可启动，文档中心只展示部署中存在的手册；本机文档数量不代表远端部署验收。

重新部署时应包含当前前后端、用户 Markdown、登记的源码地图及离线网站构建材料。保存依赖 scripts/build-docs.mjs、docs/web/、架构规格、品牌资源、Node 依赖和本地链接目标；缺少材料或只读镜像时，在完整源码工作空间维护后重新打包。

沙箱编辑的手册应下载或同步回本机，避免下次发布覆盖。文件在容器/平台重建后的保留取决于部署与持久卷；具体发布、备份与恢复证据见 [验证记录](verification.md)。

后端沿用会话认证与来源检查，成员伪造写请求仍被拒绝。审计动作 `documents.save` 仅记录路径和前后摘要，不记录全文。接口见 [接口与权限](reference.md)，实测范围见 [验证记录](verification.md)。

## 验证命令

```sh
node --test tests/documents.test.mjs
npm run build
PLAYWRIGHT_CHANNEL=chrome npm run test:documents:browser
npm test
npm run docs:build
npm run docs:check
```

API/浏览器测试使用临时数据库和文档。真实官网构建测试在临时完整源码副本完成，不覆盖用户原稿。截图与报告在 `test-results/document-center/`，不调用真实模型、MCP 或修改远端部署。
