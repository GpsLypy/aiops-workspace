# AgentScope 质量回放逐条复核：2026-10-08 续轮

## 问题

现有 `agent:eval:quality` 把脱敏案例摘要重构为两个合成问题，核对本机临时 DTS 链路的自动证据，并将结果标为待人审。质量台账的来源复核与 DTS 180 条发布评测的人工模板各有用途，但没有针对这份两例回放报告的逐条结果复核入口。报告中的 `humanReview=pending` 因而无法形成绑定当前输出的可检查记录。

## 本轮范围

1. 为现有回放报告生成逐条人工复核模板，绑定报告原文件 SHA256、候选源码、质量台账和重构问题摘要，以及每条输出摘要和执行阶段。
2. 检查复核记录的案例覆盖、重复项、审核人、时间、结论与证据引用；报告、答复或候选变化时阻断沿用旧复核。
3. 只新建权限受限的本地文件，不覆盖报告或复核记录；区分待审、拒绝、已完成与输入错误。
4. 同步运行指南、验证记录、脚本地图与入门页进展，并执行本地专项、全量、构建和离线文档检查。

## 用户授权的工程复核续轮

用户要求由 Codex 完成可执行的复核。两条待审只阻断质量检查，不阻断本地启动、使用或继续开发。续轮保留逐条审查和证据门禁，增加 `reviewerKind=human|ai|unspecified`：AI 可完成工程复核，不能被统计为已完成人工复核。复核文件继续使用 schema v1；旧记录未声明类型时按 `unspecified` 处理，新模板显式生成该值。

复核发现原受控查询答复仅提示查看快照，没有报告问题要求的四个字段。该原报告和拒绝记录应保留；修正受控夹具，让答复从本轮成功工具结果读取 `state`、`reported_at`、`queried_at`、`freshness`，重新生成报告并逐条审查。此修正验证受控答复与实际工具证据一致，不证明真实模型自动获得同样质量。

## 边界

回放使用重构提示与合成任务 ID，跨区域案例在模型请求前拒绝。`replay_review` 表示这份固定报告的逐条工程复核是否通过；`humanReviewComplete` 仅在每条均明确声明为人工并批准时为 true。审核类型和身份由记录声明，CLI 不验证身份。任何类型的复核均不能核实历史消息的真人作者、证明真实模型质量、补齐 30 场景发布评测或批准生产，`productionAccepted` 始终为 false。
