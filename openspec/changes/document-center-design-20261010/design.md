# Design

参考用户提供的门户布局，首页用深蓝搜索区、三个实际阅读分类和分组白色卡片。采用项目既有系统字体、蓝灰正文与等宽路径；主色为 #172b50、#2858e6、#252b36、#69758a、#e5e9f0 和白色。减少徽标、阴影与重复路径，让实际文档标题和摘要承担信息层级。

单组件以空 selected 表示首页，其他值为精确文件路径；只有阅读状态请求单篇正文。pushState 为选择建立历史，hashchange 处理浏览器回退，所有导航复用 mayDiscard 和保存锁。编辑仍使用原 revision 与文档 API。

阅读目录保留后端原分类，默认展开当前分类。宽屏章节从清理后的 Markdown DOM 提取 h2/h3，重复标题生成唯一 ID。移动目录按需展开，卡片三列降至两列/一列，代码块与表格在正文内滚动。无外部字体、CDN、模型或工具请求。
