# DTS 本机只读 MCP 接入

用户要求把现有 DTS 查询任务状态 REST API 接入运维助手，在当前可访问内网的 Mac 部署并全流程验收。复用现有 Streamable HTTP MCP 客户端，不修改 DTS 后端或助手页面。

新增独立适配器：固定上游 GET 路径，默认限定 general/cn_east；任务 ID 用十进制字符串；解析 data.status 并返回有限字段、真实上报时间及新鲜度。仅提供 dts_get_job_status，不提供写操作。新增本机服务生命周期命令、接入资源与验收材料。

后续用户确认拥有该区域全部任务查看权限，增加显式 region 范围模式和现有资源的任务策略同步命令；保留业务域、区域、身份、环境及只读限制，支持恢复 allowlist。

验收包括模拟异常、真实 MCP 协议、真实 DTS 查询、应用资源绑定、真实模型对话、持久执行证据、仓库回归和离线官网同步。
