# 独立代码沙箱需求

## ADDED Requirements

### Requirement: 产品入口须以隔离验收为前提

系统 MUST 在独立 broker、最小镜像及目标部署安全验收完成前，不向用户或 Agent 暴露任意代码执行入口。不可信代码 MUST NOT 在 AgentScope Worker、应用容器、应用 UID 或持有业务凭据的进程中运行。

#### Scenario: 隔离能力尚未完成

- **WHEN** 应用仅具备当前 AgentScope Worker 和应用容器
- **THEN** 用户和 Agent 均不能提交任意代码执行任务

### Requirement: 沙箱请求绑定身份与不可变任务

请求 MUST 绑定认证用户、runId、stepId、固定源码/输入摘要和服务器限额；模型或客户端 MUST NOT 决定镜像、挂载、网络、系统用户或宿主路径。相同 jobId 与摘要 MUST 不重复执行，摘要冲突 MUST 拒绝。

#### Scenario: 相同身份重复提交

- **WHEN** 同一 jobId 和摘要被再次提交
- **THEN** 返回原任务状态且不创建第二个容器

#### Scenario: 请求企图改变隔离配置

- **WHEN** 客户端提交镜像、网络、挂载或宿主路径
- **THEN** 系统拒绝请求且不启动任务

### Requirement: 每个任务使用有界、独立、禁网的环境

每个任务 MUST 使用一次性隔离环境，默认禁网、只读根、独立临时盘、无应用源码/凭据/Docker socket，并具备 CPU、内存、PID、时间、磁盘和输出限额。

#### Scenario: 代码尝试读应用文件并连接外网

- **WHEN** 不可信任务读取应用数据或尝试出站连接
- **THEN** 隔离环境拒绝访问，任务不能取得应用数据或建立连接

#### Scenario: 后续任务检查临时文件

- **WHEN** 第二个任务寻找前一任务写入的临时文件
- **THEN** 文件不可见

### Requirement: 取消、未知状态与产物受控

取消、超时与故障 MUST 有可查询终态；结果未知 MUST NOT 自动重放。产物 MUST 在访问控制、大小/类型/hash 检查、扫描和用户审批后才能下载或发布；代码输出 MUST 被当作不可信数据。

#### Scenario: 任务取消后存在进程或工作盘

- **WHEN** 用户取消运行中任务
- **THEN** broker 停止任务进程组并确认工作盘回收，保留可查询终态

#### Scenario: 代码给出外部发布路径

- **WHEN** 代码输出声称应自动发布到指定路径
- **THEN** 系统仅把它作为不可信数据，未获用户批准的产物不能下载或发布

### Requirement: 合成探针与生产验收分别记录

本地合成探针 MUST 拒绝暴露应用文件的镜像，且 MUST 检查禁网、只读根、资源限额、跨轮残留与强制取消回收。开发机探针通过 MUST NOT 被表述为生产沙箱验收。

#### Scenario: 使用现有应用镜像运行探针

- **WHEN** 合成探针看到镜像内的 `/app` 或 `/app/.data`
- **THEN** 报告失败并以非零状态退出，不启用产品代码执行入口
