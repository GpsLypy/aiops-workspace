# 集成设计

独立沙箱由 socket-only broker 控制 Docker，MCP 桥只持有提交身份；既有应用 write 工具策略审批固定源码后执行，再按同一不可变关联标签只读核验。产物白名单扫描、预览摘要批准和下载完整性检查由独立 broker 管理。未确认回收的任务冻结执行容量，取消、启动和关闭均处理孤儿容器。

观测 Compose 单独持久保存 trace/指标，loopback 端口接收现有固定字段 OTLP；Prometheus 用独立 metrics token 和各工作空间标签抓取，合并直方图桶。费用 CLI 只对用户提供的标准化文件做精确金额与 token 对账，真实文件未提供时不制造账单。

质量来源台账记录本次用户确认，不保留原任务 ID 或提示。案例与评测工程复核均声明审核者类型；DTS v3 评测复核绑定每条答复、观察和 rubric，正式人工验收保持独立。保存模型入口只读读取既有加密配置，不打印地址/Key/正文，报告排他写入。源码冻结后重新生成回放/评测证据，历史文件保留。
