# AgentScope 可选 OTLP 链路出口：2026-10-08 续轮

## 问题与范围

上一轮已将每轮 trace/span ID 持久写入问答全景，并从实际完成图谱累积进程级阶段指标。但无法由外部 Collector 关联模型、MCP 和 Agent 轮次，也无法聚合多实例。此续轮增加部署级的可选 OTLP/HTTP JSON traces 出口和 W3C 出站 `traceparent`。默认两者关闭；用户请求不能自行指定 Collector、采样或传播策略。

## 本轮交付

1. 完成图谱导出固定 run/model/tool/mcp/review span，保持原持久 ID；对未导出的上下文节点折叠父链，使外部树闭合。
2. 同一随机 trace ID 决定整轮采样与传播标志；部署显式开启时向 Agent 模型和 MCP 发现/实际调用发送 `traceparent`。
3. 复用现有出口白名单与固定 DNS 请求；限制单次等待和 128 项内存队列，Collector 失败、超时或停机不影响业务结果。用固定指标观察发送、失败、丢弃及采样跳过。
4. 用本地受控模型/MCP/Collector fixture 验证字段脱敏、真实请求头、幂等、失败与关闭行为，并尝试官方 Collector 协议接收；同步部署说明、API/架构图谱及验证记录。

## 边界

本轮只覆盖应用生成的 Agent 轮次，不接收或信任入站 trace 上下文，不给固定 Runbook/直接 MCP 操作补造 Agent span。导出不包含问题、回答、模型/资源名称、工具参数、私有推理或供应商账单；外部采集器的权限、保存期限、跨实例汇总和下游服务是否继续传播需目标环境独立验收。出口是尽力而为，不能充当审计或质量放行依据。
