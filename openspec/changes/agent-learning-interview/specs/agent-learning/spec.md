# Agent 学习与面试要求

## 课程证据

- 学习者 MUST 能沿概念、真实源码函数、已有实验、预期观察、面试追问推进。
- 命令与源文件 MUST 存在；预期结果 MUST 明确区别于学习者的实测记录。
- 文案 MUST 区分工程 fixture、真实 SDK 和真实模型/生产证据，标明当前未实现能力。

## 交互

- 引导页 MUST 提供「学习与面试」入口和至少六个主题。
- 面试答案 MUST 初始折叠，支持键盘展开及切换主题。
- 笔记/自评 MUST 明确仅保存在当前学习视图；导出 MUST 只包含教学材料与用户的本次填写。
- 静态学习操作 MUST NOT 自动执行命令、模型请求、工具调用或资源修改。
- 320px 屏幕 MUST 可阅读和操作，不产生整页横向溢出。

## 持续迭代

- 每轮 MUST 更新主题台账、对应验证记录、文档与离线官网。
- 已交付教学材料 MUST NOT 自动被记为用户已经学完或亲自实现。
- 每日调度在当前聊天续接；未变化时保持安静，只报告新的交付、重要问题或所需用户行动。

## ReAct 实验（第 1 轮）

- 实验 MUST 使用真实 SDK、本地受控模型/MCP、独立临时数据库和仅只读工具目录；不接受真实供应商模式。
- 正常场景 MUST 核对 2 次模型请求、1 次实际工具与成功台账，以及第二次请求中的工具结果。
- 非法 JSON 场景 MUST 核对调用前拒绝、1 次模型请求、0 次工具与失败台账。
- 上限场景 MUST 核对 6 次模型请求、6 次只读步骤与整轮失败，并明确最后一次结果没有被第 7 次模型请求消费。
- 报告 MUST 区分预期/实际、记录固定源码清单摘要与运行时间，不保存提示词、工具正文或凭据；异常不应输出成功结论，命令以非零状态结束。

## 上下文与检索实验（第2个学习主题）

- MUST 使用真实锁定SDK、本地受控模型、独立临时数据库；拒绝额外参数与真实供应商模式。
- ranked/diverse MUST 在相同合成资料上只改变检索模式，核对来源覆盖、过期排除、diverse每文档最多两片段且不重叠；不要求填满五个片段。
- 历史对照 MUST 使用14个完整轮次加当前问题，核对数据库仍保留合成任务ID，而budgeted后该ID可能不在模型请求；当前重新提供ID后必须原样可见。
- MUST 核对按完整旧轮次裁剪，保留当前问题；预算统计只覆盖最近30条窗口内的候选消息，不能称为全部历史记忆统计。
- 必需输入超预算 MUST 在模型和工具调用前以422拒绝。所有六个场景实际工具调用和持久工具步骤 MUST 为零。
- 报告 MUST 分开HTTP请求体字节、上下文字节和固定fixture tokens，不以字节降幅宣称真实费用或质量收益，不宣称已证明真实模型会主动追问。

## 授权与本轮意图实验（第3个学习主题）

- MUST 使用真实锁定SDK、本机受控模型/MCP、每组独立临时数据库、test环境和单一只读工具，拒绝参数及真实模式。
- 三组 MUST 保持同一明确billing请求及允许billing/inventory的策略；billing与inventory各实际执行一次，payroll必须在调用前403且无步骤。
- MUST 对照模型提议、实际MCP、持久加密参数解密后的目标及第二次模型请求的工具结果，不只根据最终模型文本判断。
- `scenarioMatched`与`intentMatched` MUST 分开：授权内选错目标实验通过意味着复现现有缺口，不意味着保护生效；意图比较仅为脚本对合成目标的事后检查。
- 报告 MUST 保存实测计数、运行/步骤状态、时间和固定源码摘要，异常非零退出，不保存凭据、完整提示或工具正文。固定tokens不推导真实费用或质量。
- 前置绑定规范 MUST 明示尚未实现；可信本轮目标不能从待验证的模型参数自我批准。独立复核的答复门禁不能算作查询前阻止。

## 写入后的unknown实验（第4个学习主题）

- MUST 仅使用独立临时数据库、本机受控MCP和test策略，写入仅改变合成内存状态，拒绝参数/真实模式。
- MUST 通过固定工具HTTP入口创建计划并审批，持久runtime为direct/1；模型请求与tokens必须0，不称为SDK编排实验。
- MUST 覆盖发送前失败、真实写后丢弃回包、发送前取消、发送后取消；每组独立记录run/step与写请求数/实际应用次数。
- 丢回包组 MUST 确认本地上游已应用并回包后再丢弃；unknown后只读对账，读增加而写请求/应用次数不变，重复审批拒绝。
- 取消组 MUST 等挂起审批收尾再读取最终状态，不从取消API的即时响应推断远端没有副作用。
- 报告 MUST 区分观察器所知与平台可确认的事实，不把unknown普遍解释为已经写入，不把远端去重宣称为平台未重发或跨网络exactly-once。
- MUST 固定费用配置、记录白名单摘要和时间、失败非零退出；仅保存结构证据，不保存凭据和任意工具正文，不承诺强制中断清理。

## 固定双Agent与质量实验（第5个学习主题）

- MUST 使用真实锁定SDK、临时本机模型/MCP、各组独立数据库和仅只读test策略；不接受参数/真实模式。
- MUST 覆盖证据充分pass、无证据block、同一无证据候选预设错误pass、授权内错误目标block和reviewer503不可用；查询发生后block不得声称撤销查询。
- MUST 分开HTTP/execution、review和trace状态，核对返回/持久候选发布状态、实际模型/工具调用数及阶段tokens；失败reviewer不得自动重试。
- MUST 核对reviewer无工具、实际证据与持久步骤关联；不得从模型声称的工具动作推断实际执行。
- `scenarioMatched` MUST 仅表示工程行为符合预期，错误pass反例不得计作质量成功。人工评分保持pending且为空，`realModelQualityAccepted`必须false。
- MUST 记录固定源码摘要和实际时间，失败非零退出；报告不含完整问题/候选/工具正文或凭据，不由合成tokens推导真实费用、质量或相关错误概率。

## 可观测性实验（第6个学习主题）

- MUST 使用真实SDK、临时SQLite及本机预设模型/只读MCP；拒绝所有参数和真实模式。
- MUST 独立记录注入等待的实际起止与模型/工具节点耗时，不强制假设注入阶段一定是最慢阶段。
- MUST 核对工具isError的HTTP/run/step/trace与实际请求计数；成功返回degraded不得等同于业务健康。
- MUST 导出实际脱敏trace，核对终态/图引用/持久回读与幂等回放；不存在的工具快照时间与费用不得补造。
- MUST 明确固定usage只用于台账口径，真实费用null，真实质量/生产放行false；报告含源码摘要与时间，异常非零退出。
