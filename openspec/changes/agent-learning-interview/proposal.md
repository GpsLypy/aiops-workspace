# 面向学习与面试的 Agent 持续迭代

用户希望通过本项目学习 Agent 知识并准备后续面试。已有使用引导侧重资源配置，缺少从概念、源码、实验到工程表达的连续路径。本轮建立学习入口、可复现实验课程、面试问答及持续迭代台账。

目标是让学习者能解释现有行为并取得自己的验证证据。课程不宣称训练了模型，也不把项目既有功能或自动生成的材料算作用户个人实现。未来优先围绕不懂的边界做小实验，再决定是否改变生产能力。

用户已选择每天北京时间 09:00 在当前聊天继续迭代。调度由桌面应用管理，项目内台账保存主题和验收进度，不新增业务 scheduler 任务。本地未找到 OpenSpec 技能，沿用仓库 proposal/design/spec/tasks 格式；不宣称完成 OpenSpec CLI 校验。

2026-10-04 续接第 1 轮：在学习入口基础上新增可运行的 ReAct 教学脚本与讲义，用三个本地场景解释正常往返、参数校验和调用上限，输出实测报告。运行时和产品界面行为不变。

同日全天循环2推进第2个学习主题：新增上下文与检索六组本地实验，区分来源覆盖、完整轮次裁剪、数据库保存与本轮模型可见性。输出独立中文/JSON报告与讲义，不增加长期记忆、向量库或模型调用策略；日程按用户的全天窗口临时加速，见学习台账。

同日全天循环3推进第3个学习主题：用同一明确用户请求与两个已获授权的合成目标，复现授权内选错目标仍可执行，另以越权目标作对照。新增本地脚本/讲义，提供前置目标绑定的待实现规范；本轮不实现意图识别或修改治理链路，也不接入真实业务系统。

同日全天循环4推进第4个学习主题：新增固定执行器的写入结果未知实验，以本机响应丢弃和取消屏障解释unknown、只读对账与不重放。每场景临时数据，所有写入仅改变合成fixture内存；记录direct运行标签，不冒称调用了模型或SDK编排。

同日全天循环5推进第5个学习主题：以五组真实SDK/受控模型实验核对固定独立复核的发布门禁，包含缺证据时预设错误pass的反例。报告将平台是否符合预期与真实模型质量分开，配套尚未填写的人工评价表；不增加复核Agent、重试或生产放行能力。

2026-10-05全天循环6推进第6个主题：增加本机观测实验，解释模型/工具等待、工具失败、执行成功但合成业务异常。只使用实际trace、台账和独立fixture观察；不新增遥测系统、不推算真实费用。
