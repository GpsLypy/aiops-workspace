# 聊天正文流式契约

## Requirement: 普通聊天在模型完成前显示正文

模型响应为有效 SSE 时，Node MUST 在终态之前转发正文增量，页面 MUST 追加到同一条未完成回答；不得先收齐答案再用定时器伪造生成过程。Chat Completions 与 Responses 均适用，中文 UTF-8 拆包不丢字。

### Scenario: 分段完成

- 上游发送第一段并保持连接未完成。
- 浏览器已经显示第一段，执行仍为 running。
- 上游发送后续文本和有效终态，页面收敛到持久化完整回答，刷新不重复。

## Requirement: 工具与私有内容隔离

工具调用参数、reasoning 增量和复核 JSON MUST NOT 发送为可见正文。进入工具阶段 MUST 清除暂显文字；工具执行保留原权限、参数验证、次数与幂等约束。独立复核模式 MUST 继续仅在通过后发布候选答复。

## Requirement: 不完整结果不得保存为成功回答

缺少上游终态、协议错误、取消或流中断时 MUST 清除浏览器草稿，不将半截正文保存为 assistant 成功消息。保留执行记录供核对，不自动重放。供应商明确返回完整 JSON 时 MAY 兼容整段显示。

## Requirement: 可访问的生成状态

生成消息 MUST 具有未完成提示，沿用安全 Markdown 渲染；减少动态效果偏好 MUST 关闭光标闪烁。用户向上阅读历史时 MUST NOT 被每段增量强制拉回底部。
