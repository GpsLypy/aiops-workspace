## ADDED Requirements

### Requirement: 自主委派必须显式启用并有界

系统 MUST 仅在认证用户传入 delegationMode=auto 时提供内部委派工具；默认 off。每批 MUST 不超过3个子任务，每轮 MUST 不超过4个，委派深度 MUST 为1，主子模型合计 MUST 不超过12轮并保留独立复核预算。

#### Scenario: 默认关闭或超限

- **WHEN** 默认请求没有开启委派，或模型提出超限、递归或未知字段
- **THEN** 不提供委派工具或拒绝请求，不创建越界子 Agent

### Requirement: 子任务必须继承治理边界

子 Agent MUST 使用独立上下文，身份与执行预算、超时、取消、目标绑定 MUST 来自父执行。子工具 MUST 为主授权资源与子领域绑定的交集且仅只读；调用前和结果汇总前 MUST 复核身份与资源版本，不绕过Schema、工具策略或目标绑定。

#### Scenario: 子任务要求越权或不同查询目标

- **WHEN** 子 Agent 选择未经授权的资源、写工具、错误目标，或资源在途撤权
- **THEN** 真实调用被拒绝，父任务可见真实失败状态，不将失败记为成功

### Requirement: 子任务运行必须可靠回收与持久记录

系统 MUST 持久保存子任务父执行关联、状态、加密输入结果、时间和用量；启动后遗留活动子任务 MUST 标记中断且不自动重放。相同请求幂等回读 MUST 不再创建或运行子任务；父执行取消 MUST 传播至全部活动子 Worker。

#### Scenario: 取消、重启或幂等回读

- **WHEN** 用户停止父执行、进程重启或重发相同requestKey
- **THEN** 子任务取消或中断、没有孤立活动Worker，回读只返回既有持久结果

### Requirement: 全景必须表达真实父子处理链

全景 MUST 展示实际委派、子 Agent、权限上下文、预算、模型工具、结果回传与汇总的状态、耗时、身份和依赖。图谱 MUST 支持旧version=1快照、实时与持久回读、键盘操作、320px列表和本地JSON导出。图谱 MUST NOT 包含私有推理、原始任务提示、敏感工具参数正文或凭据。

#### Scenario: 子任务并行、失败和历史回看

- **WHEN** 主 Agent 委派多个子任务且其中一个失败
- **THEN** 全景按身份区分父子节点、展示实际分支依赖和失败，刷新与导出仍保持同一记录

### Requirement: 验证与文档必须匹配实际范围

系统 MUST 完成本地真实AgentScope SDK的模型/MCP夹具集成验证、浏览器层级与交互验证、全量回归、构建及官网同步检查。文档 MUST 明确部署、真实模型质量、实际DTS与生产验收边界。

#### Scenario: 本地验收通过

- **WHEN** 本地夹具和真实SDK验证通过
- **THEN** 记录本地工程结果，不宣称已发布其他实例或完成真实业务质量验收
