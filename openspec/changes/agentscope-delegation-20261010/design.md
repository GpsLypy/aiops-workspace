# 实现设计

委派采用 Agent-as-tool：Node 提供严格参数的内部 delegate_agents，主 AgentScope Worker 通过既有模型/工具原始调用匹配请求 Node。Node 校验身份、已发布配置、资源交集和限额，创建同父执行下的独立子 AgentScope runtime，将结构化结果回填主模型上下文。子 Agent 不注册委派工具，最多三轮模型/工具往返。子 Worker 使用独立 cold 启动以避免主 Worker 占满 prefork 池导致嵌套等待死锁；子任务并发有界，共享执行额度、超时和取消。

委派任务和结果以现有主密钥加密入表；用户可见摘要只含身份、状态、用量与时间，不回放提示词或敏感工具正文。每个子模型/工具请求沿用 Node 模型出口、Schema与策略校验、显式目标绑定和持久步骤去重；失败回传原状态，主 Agent可汇总部分结果而不能把失败作为完成。独立复核接收实际子任务工具证据，仍无工具。

全景沿用version=1，节点加可选agentRunId、parentAgentRunId、parentNodeId，用稳定父子身份表示包含关系，用原edges表示数据处理依赖。只记录受理后的实际节点，预算、权限和上下文节点描述应用实际执行的检查，模型拆分理由和私有推理不采集。导出及实时/持久回读包含相同身份。
