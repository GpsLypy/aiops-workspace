# 需求

- GIVEN 已授权渠道 WHEN 任务完成 THEN 在结果事务中生成唯一事件和各渠道投递，失败不改变巡检执行结果。
- GIVEN 配置正常条件 WHEN 实际工具结果满足全部条件 THEN 结论正常；不满足为异常；未取得有效证据或数据过期为无法判断。
- GIVEN 异常模式 WHEN 结论重复且尚未达到提醒间隔 THEN 抑制推送；变化或开启的恢复条件满足 THEN 入队。
- GIVEN 对端临时故障 WHEN 后台重试 THEN 使用相同消息快照和幂等键，记录次数和下次重试；达到上限或永久错误 THEN 可查看失败并重发。
- GIVEN 用户权限被撤销、用户停用、渠道停用或配置变化 WHEN 消息待发送 THEN 阻止发送且显示原因。
- GIVEN 重启 WHEN 任务未完成 THEN 标中断并产生通知，不重放任务；待投递消息继续处理。
- GIVEN 成员账号 WHEN 查询其他人的投递或使用未授权渠道 THEN 服务端拒绝；API 不返回 URL 中密钥或凭据。
- GIVEN 桌面或窄屏 WHEN 打开通知中心、任务表单和记录 THEN 可完成配置、预览、测试消息、状态筛选及失败重发，不出现空白页面。
