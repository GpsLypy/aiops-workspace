# 独立复核规范

## 默认与预算
- 未选择 independent 的请求 MUST 保持单 Agent 路径和既有六次上限。
- independent MUST 为分析最多五次与复核最多一次，共用费用、取消与超时。
- 更改 reviewMode 后复用同一幂等键 MUST 被拒绝；同一请求重试 MUST 返回持久结果，不重放。

## 权限与数据
- 复核 MUST 使用独立 AgentScope 上下文且没有工具权限，不传递供应商 reasoning 或额外未授权资料。
- 权限撤销或所用资源发生变化 MUST 在复核前阻止继续。
- 证据太大、格式无效、模型错误或工具尝试 MUST 不发布候选答案；取消 MUST 不变成成功。
- 待审批步骤 MUST 跳过复核；模型意见 MUST NOT 批准写操作。

## 结果
- 复核只可返回严格的 pass/空 reasons 或 block/非空已知 reasons。
- 消息 MUST 持久保存可回看的阶段统计和结果，不存候选草稿与原始复核输出。
- UI MUST 区分模型复核、人工批准和业务健康；默认关闭，支持键盘及320px。

## 出口与故障收尾

- 复核输入 MUST 在组装外层 JSON 前检查内嵌 JSON 字符串，不因转义字段隐藏已有凭据模式；未修改数字原文 MUST 保持，尤其是 int64 ID。
- 超出递归保护上限 MUST 停止复核，不能截断证据后批准候选答复。
- 复核 Worker 故障 MUST 中止本阶段挂起模型请求，不重试；用户取消仍终止整轮执行。
- 网页 MUST 按消息元数据保留历史复核结果；开关刷新或新会话后恢复关闭，不改变历史记录。
- 测试通过 MUST NOT 被表述为真实模型收益、DTS写权限或生产上线批准。
