# 第六期：独立证据复核

当前所有对话已统一 AgentScope，但答案仍由单个 Agent 形成。真实 DTS 验收曾发现用户指定越界区域、模型却改查授权区域的目标替换；一次执行成功不能证明答案符合用户请求。

增加默认关闭、每次聊天显式选择的分析 Agent → 复核 Agent 固定流程。分析沿用已授权工具；复核在独立 Worker 上下文中只读本轮证据，不持有工具、不新增委派。严格结构化复核通过才展示分析答复，否则返回固定提示。审批计划直接交现有人工审批，不经模型复核批准。

这是一项可测的受限多 Agent 能力，不宣称真实模型质量提升或替代权限/人工审核。复核发生在分析之后，不能阻止或撤销分析阶段已完成的查询，也不解决所有自然语言范围歧义。对照 DTS 真实源码核对边界，真实服务和资源配置不由本期自动改动。

未安装 OpenSpec skill，使用仓库既有 proposal/design/spec/tasks 格式；不宣称 CLI 验证。
