# Proposal

## Why

已有独立架构图未进入应用静态构建，文档链接只能提示源码路径。用户要求上线图形可视化，并参考深色分区、节点连线与流向动效图，选择系统架构加请求流程演示。

## What Changes

- 文档首页和阅读页提供新标签页入口，保留编辑草稿。
- 双视图展示真实源码的系统边界、请求主链、工具循环和审批门禁。
- 复用Archify交互：节点搜索/聚焦、缩放、主题、可暂停动效和导出。
- Vite开发服务和生产构建提供一致的固定静态地址；沿用助手沙箱发布，为固定图形响应头受控重启。

## Capabilities

### New Capabilities

- `architecture-viewer`: 系统架构和请求流程图形查看器。

### Modified Capabilities

无API或数据库契约变更。

## Impact

文档中心入口、Vite静态打包、图形规格/产物、专项浏览器验证、手册及沙箱发布记录。增加静态资源安全响应头模块，无新增依赖，不读取真实执行状态。
