# 设计与验收边界

## 质量闭环

沿用现有候选源码/语料摘要和人工验收概念，为脱敏真实问题或失败样本建立本地可审查格式。样本来源、人工 rubric、判定证据和候选身份必须显式记录；校验失败或资料缺失时退出为未满足门槛。CLI 不连接生产、不会自动批准上线，也不会将旧版评测报告静默迁移为当前报告。

## 可观测性

单轮全景继续保持有界、脱敏。一次运行分配 trace ID，节点使用 span ID 与父级引用，随现有持久记录和 NDJSON 回读保持一致。仅从实际完成的 trace 计算固定阶段和状态的进程内聚合指标；避免用户、工具名、问题正文和参数成为指标标签。重放持久运行不得重复计数。现有基于配置单价的费用仍只是估算，不能标为实际账单；本轮不发送 OTLP。

## Worker 临时文件

冷启动和预加载启动均让 Python 的临时文件路径属于本轮私有目录。父进程不能把某一轮的目录复用给下一轮，子进程退出后回收目录；异常和取消走同一清理路径。该改动只缩小临时文件的共享面，不提供文件权限或网络隔离。

## 验收

专项测试分别覆盖：质量样本缺失/标注缺失/摘要过期和有效格式；trace ID 持久与回读一致、敏感内容不进入指标、失败与幂等计数；cold/prefork 临时文件目录和清理。功能共享行为运行 `npm test` 与 `npm run build`，文档运行 `npm run docs:build` 与 `npm run docs:check`，页面文案在浏览器核对桌面和窄屏。
