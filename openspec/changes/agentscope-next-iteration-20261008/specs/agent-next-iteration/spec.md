# AgentScope 下一轮可验证需求

## ADDED Requirements

### Requirement: 质量案例来源与候选摘要必须参与验收

质量样本校验 MUST 拒绝来源不明、人工标注不完整或不匹配当前候选摘要的输入；MUST NOT 将合成用例、未核实的历史候选或旧报告自动称作真实用户质量验收。历史候选 MUST NOT 计入真实用户问题或观察失败门槛。

#### Scenario: 历史消息来源尚未核实

- **WHEN** 一条从本机历史提取的 user-role 消息已脱敏，但真人作者或独立业务场景尚未核实
- **THEN** 案例可进入人审台账，但 `real_problem` 保持阻断，不能以该消息宣称真实用户质量通过

#### Scenario: 复核缺失或摘要过期

- **WHEN** 人工复核待完成，或复核绑定的源码/语料摘要与当前候选不同
- **THEN** 质量检查拒绝放行，旧复核不得自动沿用

### Requirement: 重构质量评测必须保持来源和阶段边界

质量重构评测 MUST 使用独立合成目标和临时本机工具，MUST 记录当前源码、质量台账和重构问题摘要；模型前授权拒绝 MUST 与实际模型/工具执行分开记录。逐条人工复核 MUST 绑定报告和答复摘要，MUST NOT 将重构场景或受控模型结果称作真实用户质量放行。

#### Scenario: 历史摘要被重构为本机问题

- **WHEN** 评测从脱敏摘要生成新的合成任务问题，并取得工具查询或前置拒绝的自动证据
- **THEN** 报告明确区分两种测试阶段，保留人审待办，且真实来源与生产放行门禁仍阻断

### Requirement: 模型请求诊断必须可选且最小化

模型请求阶段诊断 MUST 默认关闭；开启后 MUST 只记录固定阶段、结果、耗时、取消来源和 SSE 终态，不记录提示词、模型名、URL、请求头、响应正文或原始错误，也不得改变超时、重试和用户可见错误。

#### Scenario: 模型请求失败或在本地出口检查被拒绝

- **WHEN** 管理员在测试实例开启诊断，且模型请求超时、连接失败、流未完成或在本地被拒绝
- **THEN** 进程日志只有固定字段诊断，可区分失败阶段，但不从日志推断供应商根因

### Requirement: 运行关联与阶段指标必须保持一致且脱敏

本轮新增的运行关联 ID MUST 在实时、持久和回读路径保持相同；阶段聚合 MUST 只使用实际完成记录与固定低基数标签，MUST NOT 输出问题正文、工具参数或凭据。

#### Scenario: 完成的 Agent 运行被重新读取

- **WHEN** 同一运行先通过实时事件展示，再从持久消息回读，并汇总阶段指标
- **THEN** 运行和节点关联 ID 保持一致，指标不因回读重复计数且不包含敏感正文或参数

### Requirement: Worker 临时文件必须属于本轮目录

运行时临时文件 MUST 属于本轮私有工作目录并在正常/失败回收路径得到清理；文档 MUST 明确该机制不是操作系统沙箱。

#### Scenario: Worker 正常完成或发生可处理故障

- **WHEN** cold 或 prefork Worker 在本轮创建临时文件后正常完成或进入失败收尾
- **THEN** 文件位于该轮私有目录，收尾清理目录，且文档不把同一系统用户的文件与网络权限描述为隔离

### Requirement: 入门与验证文档必须说明能力边界

入门页面和验证记录 MUST 分辨既有能力、本轮切片与尚未验收的目标：单工具只读目标绑定、开发机 OTLP 探针和独立沙箱协议的局部证据 MUST NOT 被表述为真实模型质量放行、生产观测接入或可运行不可信代码的沙箱。

#### Scenario: 仅完成本机回归和合成探针

- **WHEN** 本地目标绑定、OTLP Collector 或沙箱探针通过，但真实质量样本、完成人审或目标环境验收仍缺失
- **THEN** 入门页面与验证记录说明实际证据及未验收边界，不宣称生产放行
