# 独立本机 Python 沙箱执行服务与产物生命周期

## Why

入门页的受控执行计划已完成协议和本机固定探针，但没有可提交的独立执行 broker，也缺扫描、审批和产物回收。用户要求继续完成该页计划，需要可运行且如实说明边界的本机实现。

## What Changes

- 新增独立 Unix socket broker，服务端令牌映射租户/用户/角色，固定源码请求、幂等、持久状态及未知状态恢复。
- 复用 Docker 隔离合约，以固定本地 Python 3.12 镜像运行有界源码；容器内无应用目录、凭据、网络、宿主挂载或 socket。
- 新增产物收集、保守 text/json/csv 白名单扫描、私有隔离、独立管理员纯文本预览与摘要绑定显式审批、批准后下载、TTL/删除回收。
- 新增可选 MCP write 执行/read 状态桥，要求产品实际 `risk=write` 策略、精确关联标签范围/幂等/只读核验/恢复手册，不提供批准或下载工具。
- 新增隔离单测与本机 Docker+真实 SDK 验收，不修改实际应用资源和数据库。

## Impact

新模块位于 `integrations/agent-sandbox/`，不增加共享 schema/引擎/API 字段。仅 Python 源码首期，不支持上传输入。生产系统用户/内核威胁、应用可信执行 ID 自动绑定、共享连接器内用户隔离和生产恶意文件引擎另需验收。
