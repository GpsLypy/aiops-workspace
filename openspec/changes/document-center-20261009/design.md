# 设计

沿用现有蓝白工作空间：蓝 #2858e6、浅蓝 #eef3ff、正文 #252b36、灰 #748095、分隔 #dfe5ef、白 #ffffff。标题使用现有中文无衬线字体，正文系统字体，文档路径和编辑器使用等宽字体。页面为可搜索目录与阅读工作台两栏，窄屏堆叠；文件路径是文档身份，当前文档以蓝色竖线标记。编辑支持原稿与实时预览，长表格内部滚动。

后端从模块位置确定仓库根；发现 README.md 与 docs、deploy、integrations 内的 Markdown，排除 codemap 和隐藏/构建/依赖目录及所有符号链接。官网章节映射仅用于分类，标题来自文件实际一级标题。列表返回可搜索正文，单文档读取返回 SHA256 revision。仅管理员 PUT 可写，大小上限512KiB，禁止新增/删除和任意路径。后端沿用 Cookie、Origin 和 JSON 门禁，审计只保存路径/摘要。

同一实例保存串行化，原子同目录替换、再次校验 revision，执行固定 Node 文档构建与检查，失败恢复原稿和旧官网。不运行文档代码。官网脚本仍为可信固定源码。离页/换文档提醒未保存修改，保存中阻止切换；并发读取过期响应丢弃，失败保留草稿。只读文件系统返回明确失败，源码缺失返回说明。本轮本机验收，不部署公司沙箱或发布生产。
