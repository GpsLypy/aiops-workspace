# 项目用户文档中心

用户需要在工作空间直接查看和修改本项目用户文档。现有 AgentScope 入门只有学习视图，完整 Markdown 文档散落在 docs、部署包和集成目录。

在左侧 AgentScope 入门正下方新增同级「文档中心」与 #documents 直达入口。按官网章节分类并补充项目说明、部署与集成、教学附件，提供标题/路径/正文搜索、阅读预览、Markdown 编辑和下载。登录成员可读，管理员可保存到原文件。

保存使用内容摘要检测冲突，串行执行原子替换、离线官网重建和检查；失败回退并保留用户草稿。仅发现公开文档目录的 Markdown，不暴露配置、数据、任意文件或源码执行入口。同步文档、地图、测试与实际验证证据。
