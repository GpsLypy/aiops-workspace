# 问答全景要求

## 真实记录

- 新问答应有版本化全景，独立于可选证据报告开关。
- 模型请求、工具、复核、目录与来源记录必须来自实际执行，不从模型正文推断。
- 待审批工具不得显示为已执行；失败、取消、复核阻止必须保留。
- 快照不得包含输入正文、工具参数/原文、密钥、候选答复或推理内容。
- 刷新、幂等回读和会话 ACL 应沿用持久消息语义。

## 用户体验

- 用户能查看实际节点、上下游关系、摘要和耗时，并下载 JSON。
- 用户能用键盘和 320px 屏幕完成查看；旧消息无快照不生成虚假图谱。
- 用户能从引导进入资源配置与新聊天，编辑/复制/下载教学模板；模板与真实运行明确区分。

## 验证

真实 AgentScope SDK + 本地受控模型/MCP 覆盖流程与回归。浏览器覆盖实时/历史转换、下载、键盘、窄屏和引导路径。记录真实供应商与生产未验收边界。
