# 问答全景与 AgentScope 使用引导

现有产品拥有治理、审批、证据与独立复核，但用户难以串联每轮实际处理路径，也缺少从模板到真实验证的学习入口。本期增加持久、可交互的问答全景，以及 AgentScope 入门工作台。

全景基于系统实际观测，展示上下文、资料、工具目录、模型、工具、复核与答复的依赖、状态和耗时。引导提供当前可见配置状态、可编辑 Skill 模板和开发边界。沙箱、目标绑定、质量评测等后续能力以明确的优先级和验收条件记录，不宣称已经实现。

未找到已安装的 OpenSpec 技能，沿用仓库 proposal/design/spec/tasks 形式，不宣称 CLI 校验。用户已授权自主设计与实现。
