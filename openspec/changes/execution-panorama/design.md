# 设计

## 可观测数据

Node 引擎建立本轮记录器，模型桥接在真实请求开始和结束时回调。节点的上游边表示实际输入/处理依赖，不解释模型内部思考。运行期间通过 NDJSON trace 事件发送快照；最终结果写入既有 messages.metadata.executionTrace，沿用会话权限与备份，不增加表或外部遥测服务。

版本 1 保存 runId、时间、状态、节点和边。只采集受控摘要、资源身份、版本、计数与模型用量，不采集问题、提示、工具参数/原文、候选答复或 reasoning。节点和边有数量上限，资源过多时聚合。等待审批、工具失败、发现失败、复核拦截与取消保留其真实语义。

## 界面

聊天用紧凑入口打开蓝白依赖画布：连线、节点状态、耗时、所选上游高亮构成视觉主轴。节点详情展示工作摘要、前后依赖；提供缩放、全图、列表和本地 JSON 导出。窄屏可用列表阅读，键盘可选节点并退出弹窗。历史无数据不补造记录。

入门页面沿用导航和现有权限信息，以能力接线和可编辑 SKILL.md 为核心。三种场景不调用模型、保存资源或自动执行。计数只代表已配置资源，不代表连接已验证。

## 边界

图谱记录引擎受理后的本轮过程，不包含前置 HTTP 拒绝、队列等待或后续人工审批生命周期。图谱不是业务健康结论；系统进程硬退出时未保存的在途快照不会恢复。当前 Python 子进程隔离不是任意代码沙箱。新建代码执行工具、分布式运行、OpenTelemetry 和长期记忆留在未来路线。
