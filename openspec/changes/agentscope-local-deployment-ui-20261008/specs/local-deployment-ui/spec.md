## ADDED Requirements

### Requirement: 已部署本机能力必须有直接可见的入口

Guide MUST 在既有视图同层级提供「部署与验收」，展示服务、历史验收和账单工具；MUST 明确区分本次探测与历史证据，并支持 320px、键盘焦点及可读加载/空态/失败态。

#### Scenario: 管理员打开部署视图

- **WHEN** 已登录管理员选择「部署与验收」
- **THEN** 页面读取管理员状态接口，显示各项本机服务的固定地址、实际探测结论和检查时间，并单独显示历史验收日期

#### Scenario: 普通成员打开视图

- **WHEN** 非管理员选择该视图
- **THEN** 页面显示权限说明且不发起管理员请求；直接调用管理员接口仍被后端拒绝

#### Scenario: 刷新失败

- **WHEN** 状态刷新发生网络故障
- **THEN** 页面显示可读错误与重试入口，不把先前快照标为本次健康成功

### Requirement: 本机状态 API 必须只访问固定且有界的目的地

`GET /api/local-services` MUST 通过工作空间身份及管理员校验，仅访问代码固定的 loopback 健康端点；MUST 限时、限制解析字节和禁止重定向，MUST NOT 接受外部地址、文件路径、令牌或触发模型/代码工具。生产环境默认 MUST 不探测开发服务或读取本机报告。

#### Scenario: 用户传入替代 URL 或路径

- **WHEN** HTTP 客户端附带 URL、路径或部署参数
- **THEN** 服务不能访问该值指定的目标或文件，目的地始终为服务端固定白名单

#### Scenario: Collector 入口返回 405

- **WHEN** 固定 Collector GET 返回预期 HTTP 405
- **THEN** 仅记录入口有响应，不能声称当前 trace 已写入、端到端链路通过或生产就绪

#### Scenario: 探测超时或重定向

- **WHEN** 本机端点超过规定限时或返回重定向
- **THEN** 记录未响应或未知且不跟随新目的地，不回显端点正文或内部异常

#### Scenario: 沙箱 MCP 健康入口返回成功

- **WHEN** 固定沙箱健康入口返回 200 且 `ok=true`
- **THEN** 仅显示 MCP 入口可达，不据此确认 broker、当前执行容量或再次通过安全隔离

### Requirement: 历史验收摘要必须保护文件和证据边界

状态接口 MUST 只读取固定白名单内、有界、安全的普通报告文件；MUST 只输出固定安全字段及保存的合法日期，MUST NOT 回显秘密或将历史通过当作当前候选通过。

#### Scenario: 报告为符号链接或异常文件

- **WHEN** 报告指向白名单外、不是安全普通文件、过大或无法严格解析
- **THEN** 返回缺失或未知摘要，不读取任意宿主文件，不暴露文件路径或原始内容

#### Scenario: 旧验收没有当前源码绑定

- **WHEN** 报告保存通过结论但没有可核对的当前候选摘要
- **THEN** 页面标为对应日期的历史验收，实时状态独立探测且当前源码验收保持未核实

#### Scenario: 报告声称未来完成

- **WHEN** 报告时间在当前时间之后
- **THEN** 该历史证据保持未知，不能显示通过或以当前时间替代

### Requirement: 账单接口必须仅在内存执行严格对账

`POST /api/local-services/billing` MUST 使用管理员权限、既有 JSON/同源保护和严格两个文件信封，每份 UTF-8 内容最多 400 KiB；MUST 只接受 CSV/JSON 标准化白名单数据，在内存复用精确对账，MUST NOT 从 filename 读取或写入宿主文件、访问供应商账户或调用模型/工具。

#### Scenario: CSV 与 JSON 输入成功匹配

- **WHEN** 管理员提交合法使用量与费用文本
- **THEN** 返回输入摘要、按日期/供应商/模型/币种分组的成本和 token 结论，允许浏览器下载本次结果且服务器不保存输入

#### Scenario: 输入包含秘密字段或非法文件名

- **WHEN** 输入包含额外字段、路径、无效结构、超限内容或禁止的数值
- **THEN** 拒绝请求并返回固定脱敏中文错误，不回显原始文本、秘密值或解析异常

#### Scenario: JSON 金额采用可能丢精度的数值类型

- **WHEN** HTTP JSON 的 `estimatedCost` 或 `billedCost` 使用 number
- **THEN** 拒绝输入并要求十进制字符串，不把大金额解析丢失的小数当作数值对账吻合

### Requirement: 账单吻合不得改变认证和生产边界

账单结果 MUST 保留估算与供应商费用区别、抵扣、币种、未匹配项、缺失/估计 token；MUST 标记用户提交且来源未认证、供应商账户未验证、生产未批准。

#### Scenario: 费用一致但缺少供应商 token

- **WHEN** 金额相同而供应商费用没有 token 明细
- **THEN** 费用可显示一致，token 仍未核实，整体需复核，不能宣称完整费用验收

#### Scenario: 全部数值一致

- **WHEN** 标准化两份输入全部数值匹配
- **THEN** 数值对账显示匹配，但 `providerAccountVerified` 和 `productionAccepted` 仍为 false，真实来源边界继续显示
