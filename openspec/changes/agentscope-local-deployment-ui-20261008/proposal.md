# 本机部署与验收可见入口

本机 Collector、Tempo、Prometheus、Python 沙箱服务和账单对账工具已部署或实现，但用户在 AgentScope 入门页只能看到文字进度，无法直接确认服务状态、辨别验收日期或使用对账。用户要求继续把这些成果体现在界面。

本轮在既有 `#guide` 内增加「部署与验收」视图，提供当前本机服务探测、明确标为历史的安全验收摘要，以及管理员账单 CSV/JSON 导入和内存对账。它是本机能力的查看与使用入口，沿用现有身份和请求保护，不新建业务数据库、不调用模型或代码执行工具。

管理员 `GET /api/local-services` 只访问代码固定的 loopback 地址与报告白名单；部署报告缺失或生产部署未明确启用时展示未配置，不扫描网络或读取私有配置。`POST /api/local-services/billing` 接受两份已标准化文本，每份最多 400 KiB，在内存严格解析并复用精确金额对账逻辑，输出来源摘要、币种独立汇总和未匹配项。

实时可达性、历史验收、真实模型质量、AI 工程复核、正式人工及生产批准分别呈现。旧报告没有当前候选绑定时不能据其 `passed` 宣称当前源码已验收；Collector 的 HTTP 405 只证明固定入口响应，不能当作新链路写入或就绪验收。账单结果不验证供应商账户或输入来源。

涉及现有 Guide/API/样式、后端模块与专项测试；同时同步相应地图、运行文档、验证记录和离线官网。此轮没有服务启动/停止、产物批准/下载、任意文件读取、真实账单认证或生产发布控制。
