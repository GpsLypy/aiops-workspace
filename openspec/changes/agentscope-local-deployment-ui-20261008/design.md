# 部署事实、历史证据与管理员工具

## 页面职责与视觉

对象是已经在本机运行工作空间的管理员；页面的单一职责是回答「哪些服务正在响应、之前验证了什么、如何使用账单工具」。入口为既有 AgentScope 入门页中的「部署与验收」，与开始使用、学习及开发视图同层级，沿用现有导航和用户角色。

遵循 frontend-design，沿用页面已有的蓝色 `#315fff`、正文 `#202736`、辅助字 `#69758b`、边线 `#e2e8f2`、底色 `#f6f8fc` 与待核实琥珀 `#89631e`。标题延用 Avenir Next / PingFang SC，正文沿用中文无衬线，地址、日期、金额使用 SFMono-Regular / Consolas。新视图的识别元素是同一项能力并排显示「刚刚探测」与「历史验收日期」的事实栏；状态颜色必须附文字，不靠装饰或大数字代表批准。

页面先显示本机状态与刷新按钮，再显示历史验收和范围，最后提供账单工具。窄屏改为单列，表格可在局部滚动且整页无横向溢出；所有控件有标签、键盘焦点和明确繁忙/成功/错误状态。非管理员看到权限说明，不发起受保护请求。错误保持可读，刷新失败不把旧结果标成刚刚成功；不存在报告显示暂无证据。

```text
AgentScope 入门 / 部署与验收
  本机服务                         刷新状态
  服务  固定地址  本次探测  检查时间
  历史验收                         报告日期 / 范围
  观测 / 沙箱 / 质量 / 目标绑定     通过、失败或未核实
  账单对账
  使用量文件  +  供应商费用文件     开始对账
  币种汇总 / 差异 / 来源与边界      下载本次结果
```

## 本机只读 API

路由在已有 `/api` 身份中间件之后装配，两接口均使用 `admin` 门禁，并保留 `Cache-Control: no-store`、POST JSON 与同源检查。前端传入的地址、查询参数、文件路径或部署配置都不能改变目的地。

固定探针为 Collector `127.0.0.1:4318/v1/traces` GET（预期 405，标记入口响应）、Tempo `127.0.0.1:3200/ready` GET、Prometheus `127.0.0.1:9090/-/ready` GET，以及沙箱 MCP `127.0.0.1:43130/health` GET（200 且 `ok=true`）。沙箱健康端点只证明 MCP 进程响应，不查询 broker 或当前容器容量，页面不能据此声称 Python 当前可执行或隔离重新通过。不附加工作空间、metrics、模型或 broker 令牌，不跟重定向，单探针至多 1800 ms，对需要解析的响应实行字节上限；响应摘要只含固定服务标签、状态和时间。失败与未知不能变为通过。GET 不调用 `/v1/traces` POST、模型、MCP 工具、Docker CLI或业务写入口。

默认生产环境不读取开发报告或探测本机端口；开发环境仍须相应合法部署报告存在才探测该服务。允许固定的进程内部依赖注入用于临时测试，HTTP 无法启用或更换它。地址调整、远程部署或生产开放属于后续明确配置与验收范围。

## 历史证据

文件名在代码中固定，涵盖观测本机状态/验收与沙箱部署/验收。读前验证真实路径、普通文件、非符号链接、权限和大小（最多 512 KiB），不能遍历目录或由 HTTP 指定路径。读取失败返回固定缺失/未知状态，不能暴露宿主路径、错误正文、配置、token、提示词、代码或产物。

从报告中仅选择固定检查名、布尔结论、合法且非未来时间及有限数值，重新核对保存的检查结论与所需清理条件；不得直接透传未知字段或错误文本。历史 `passed` 不证明当前服务状态或当前候选源码。没有摘要绑定的报告明确为历史证据，日期缺失或不合法时不能补成当前时间。即使报告有候选摘要，也须在声称当前候选匹配前真实核对，页面时间只表示该次记录。报告 reader 使用非阻塞只读 open 后 fstat 验证，FIFO 等特殊文件不能让读取一直等待。

## 账单内存 POST

请求为严格对象 `{ usage: { filename, content }, invoice: { filename, content } }`。文件名仅用于选择 `.csv` 或 `.json`，接受单一 basename，不允许宿主路径、URL、目录分隔符或额外字段；不会将名称用于磁盘读写。每份内容按 UTF-8 字节计最多 400 KiB，继续受全局 1 MiB JSON 请求限制。

CSV 复用已有严格引号/表头解析；JSON 必须为 `schemaVersion=1`、相应 `kind` 和 `records` 的严格信封。HTTP JSON 金额字段 `estimatedCost` / `billedCost` 必须为十进制字符串，避免 JSON number 在解析时静默丢失大金额的小数；CSV 金额已为文本。每行按原 usage/invoice 白名单验证。失效输入统一返回固定中文错误，不输出原文本、秘密字段、解析异常或字段值。输入在本次请求内处理，不保存于业务数据库、服务器报告或日志；下载由浏览器对返回结果生成本地文件。

对账仍按 UTC 日期、provider、model、currency 汇总，金额采用百万分整数精确累计。估算成本、供应商费用、抵扣、仅使用量/仅账单项和 token 来源分别保存；不同币种不折算或合并。摘要绑定用户提交的原始文本，`invoiceSource=user_supplied_unverified`、`providerAccountVerified=false`、`productionAccepted=false` 不因数值吻合而改变。

## 验证与取舍

后端专项覆盖未登录/非管理员、固定目的地与重定向拒绝、限时/响应上限、生产默认关闭、报告缺失/异常/符号链接/越界与敏感字段、真实历史日期，以及账单内存成功/差异/缺字段/超限/非法路径与秘密不回显。独立安全复核检查实际装配及信任边界。

浏览器以隔离临时账号核对视图入口、刷新、空态/失败态、普通成员说明、两格式账单导入、差异和下载；1365px 与 320px 目检和键盘操作，确认没有外部模型/工具请求。全量与构建、文档生成及链接检查由主集成收尾。

固定端口和证据白名单刻意收窄首期本机范围，不提供服务管理、联网账单认证或沙箱产物工作台。HTTP 健康不是端到端业务验收，管理员访问也不能把用户提交的账单当成供应商已认证材料。

## 2026-10-08 独立后端复审结果

只读审阅实际身份装配、固定 probe、报告 reader/安全摘要、billing 路由与复用逻辑，反馈并复验三项问题：大金额 JSON number 小数精度丢失导致误匹配，FIFO 在普通文件检查前阻塞 open，以及未来日期被接受为历史完成时间。实现已改为金额字符串、非阻塞文件读取并拒绝特殊文件、严格非未来时间。独立运行 `node --test tests/local-services.test.mjs tests/model-billing.test.mjs` 为 15/15，无失败/跳过；身份先于读取/探测，未认证和普通成员不能访问管理员接口，非法地址/路径/秘密输入不回显。

此复审只证明所读实现和本地专项范围，没有运行模型、代码任务、真实供应商对账或生产验收。新增源码会改变候选摘要，前轮 180 条受控工程复核继续保持其原摘要的历史证据，不能因该轮工程通过而把本轮候选标为验收完成。浏览器、全量、文档与离线官网检查仍由主集成阶段按实际结果完成。
