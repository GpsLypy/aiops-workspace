# 设计与验收边界

## 上下文

`AGENT_CONTEXT_MODE=recent|budgeted` 默认 recent。budgeted 在 Node 中只处理初始文本历史：以 user 开始划分轮次，丢弃窗口头部孤立 assistant，按完整轮次从旧到新移除。系统指令、授权知识、Skill、工具 schema、最新问题均不得截断；仍然超限则拒绝，不发模型请求。省略时加入固定提示并记录无正文的计数/字节统计。预算取显式 `AGENT_CONTEXT_MAX_BYTES` 与现有模型上下文剩余额度的较小值；工具循环和 Responses reasoning 不裁剪，既有预算硬门禁继续生效。无额外模型请求或 token 收益承诺。

## 检索

`AGENT_RETRIEVAL_MODE=ranked|diverse` 默认 ranked。在同一 ACL/启用/绑定/有效期过滤后的 FTS 候选中评分，diverse 先取每份文档的最高分片段，再补非重叠片段，每份最多两段，总数最多五。来源仍记录 ID、修订、文档版本和偏移；不扩展召回权限、不引入向量库。固定长文档/多文档语料对比覆盖率，不能将覆盖率等同真实诊断质量。

## 证据报告

`AGENT_EVIDENCE_REPORTS=true|false` 默认 false。Node 根据本轮持久工具步骤、来源、发现失败和上下文统计构造带版本的不可变消息快照；成功、待审批及已保存错误均生成。报告只有本轮操作状态，不从模型文字推断业务健康或根因；审批后的最新状态仍看执行中心。只保留定位证据所需字段，不导出问题/模型回答、工具参数、原始返回、凭据或连接地址。未知/待审批和没有成功工具证据均明确标注。无新数据库表或下载接口，沿用会话 ACL。

聊天使用原有蓝白体系：墨色 #202736、次级 #69758b、边线 #e2e8f2、浅底 #f6f8fc、强调蓝 #315fff、警示 #873434。正文继承系统字体，步骤/运行 ID 使用等宽字体。回答下方原生 details：`本轮证据 → 数据缺口 → 实际步骤 → 参考资料 → 导出 JSON`。折叠优先，展开后按证据类别排列，320px 单列；不添加健康绿灯或虚构诊断分数。审核设计后选择这条简洁的证据索引，而不扩展整页布局。

## 验证

测试应覆盖完整轮次、UTF-8/JSON 预算、不可压缩输入拒绝、当轮工具/reasoning 完整、无串会话、知识权限/过期/绑定、多文档与重叠片段、报告持久化/去重/审批快照/失败/敏感字段。新增本地评测分别对每个开关与组合做对照，保留实际请求字节/用量/模型与工具次数。默认、cold/prefork 全量回归、浏览器键盘/导出/刷新/320px、构建和离线文档检查均需通过。
