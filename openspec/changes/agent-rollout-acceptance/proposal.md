管理员目前只能通过部署环境缩小 AgentScope 范围，评测答案也没有可靠的人工复核汇总。增加持久化草稿、独立 SDK 预检、显式启用、暂停回退，以及绑定源码和报告摘要的人工验收工具。沿用 Node 治理和 schema v5，不调用生产系统。
