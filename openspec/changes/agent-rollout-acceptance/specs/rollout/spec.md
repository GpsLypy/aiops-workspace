# 灰度和评测验收需求

- 管理员 MUST 使用 revision 保存草稿、预检、启用和暂停；普通用户 MUST 无法读取或修改管理配置。
- 启用 MUST 依赖有效的当前草稿 SDK 探针；异步完成后 MUST 再验身份、版本、资源和部署边界。
- 网页 MUST NOT 扩大部署允许范围。暂停 MUST 让下一轮使用 legacy 基线而不重放在途工具。
- 每轮 MUST 固定无敏感字段的策略快照，并随历史结果保留；幂等重试 MUST 返回原快照。
- 验收 MUST 验证报告身份、覆盖和每条人工记录，MUST NOT 将 fixture 或过期源码报告当作真实评测通过。
- 输出 MUST 区分自动回归、真实模型评测验收和生产批准；系统 MUST NOT 自动批准生产上线。
