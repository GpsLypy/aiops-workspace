# 设计

> 历史阶段记录：其中双引擎/legacy 路由已由 2026-09-29 的 [AgentScope 唯一运行时变更](../agentscope-only-runtime/design.md) 取代；旧测试结果仅代表当时版本。

## 灰度与边界

settings 保存 version=1 的策略，包含全局 revision、draftRevision、draft、mode（deployment/active/paused）、activeRevision、active 和预检记录。PUT 草稿与 POST preflight/activate/pause 均要求当前 revision；每次成功变更递增版本并在同一事务审计。草稿和启用版本分离，保存不影响已生效版本。没有恢复 deployment 的网页入口，暂停后需显式预检并启用。

部署 AGENT_RUNTIME 与非空 AGENTSCOPE_AGENT_IDS 是能力上限。管理灰度只接受已启用且已发布的子领域，可在部署无白名单时显式包含通用 Agent。命中灰度的执行采用草稿中的三个增强选项；管理灰度范围外及暂停后均使用 legacy/recent/ranked/false。增强字节上限、Python 路径、池参数仍由部署维护。未配置网页策略时保留原有环境配置行为。

预检使用独立 driver 和本地 SDK 探针，无供应商/业务工具调用，完成后关闭。探针前后检查管理员、CAS、资源版本与部署指纹，记录仅有效五分钟；启用同步再校验，过期、草稿改动、部署或资源变化都需要重检。预检失败不改变策略。探针成功不能代表模型/MCP可用或生产验收。并发探针有单实例互斥。

每轮取得执行槽位时读取策略，在会话和资源校验后冻结本轮 runtimePolicy 快照，写入审计与结果/错误消息 metadata。排队中的请求以真正开始执行时的版本为准；在途运行不随暂停变化；请求去重仍返回原结果，不重放写操作。暂停影响之后的路由和 readiness，不终止在途操作；已预热主池保留到进程退出，管理运维 API 显示实际池状态，metrics 继续保留池计数。停用/删除/变为草稿的子领域仍受原有执行门禁拦截。重启后部署上限继续收窄保存的策略。

## 管理界面

在工作空间设置新增“运行时灰度”，沿用系统字体、蓝白色与紧凑表单。色板：墨色 #202736、次级 #69758b、边线 #e2e8f2、浅底 #f6f8fc、蓝 #315fff、警示 #873434。状态摘要是本页唯一突出元素：当前生效版本与编辑草稿并列，窄屏单列，让“已保存”与“已启用”清楚可辨。正文系统字体，版本号/运行方式等宽。范围使用具名复选框；保存、预检、启用依次操作，暂停独立且可在脏草稿时使用。显示部署限制、过期时间、冲突后的刷新提示。键盘/320px/刷新持久化验收。

## 验收工具

DTS 评测增加版本、源码内容摘要、语料摘要、实际配置与不含地址/密钥的模型身份；计算开始/结束摘要避免混入改动。独立 CLI 生成 pending 人审模板，按报告文件 SHA256 绑定人工条目，不覆盖既有复核文件。汇总重新核对完整场景×两引擎×至少三轮覆盖、唯一键、自动断言、有限数值、源码一致性、真实模型模式、人工结论、P95 和 token 总量比率。门槛显式记录，fixture 永远不能通过真实评测验收。token 比例不是货币费用，耗时不是生产容量；输出始终 productionAccepted=false。文件摘要防串报告，不提供签名/审批身份认证。

## 验证

默认及 SDK cold/prefork 全量、草稿/CAS/权限/过期/资源改变/重启部署收窄、失败探针清理、暂停就绪/在途快照/幂等、验收缺项与伪造汇总拒绝、浏览器与构建、文档同步。所有运行使用临时数据库和本地工具。镜像/容器按变更后的源码重建；未取得的真实质量、安全接受与目标部署证据继续开放。
