# 设计

以现有白色/蓝色工作空间为基础，采用截图的灰底胶囊、图标/名称/说明三行列表和蓝色勾选。沿用界面字体，标题14px、说明12px、默认标记10px；白 #ffffff、灰 #f1f3f6、正文 #202736、次级 #59667a、蓝 #315fff。无需连续滑条：三档可直接辨认，键盘和窄屏菜单均可使用。

配置/聊天字段 model_reasoning_effort 为 low/medium/high/null；聊天未指定时继承。旧配置默认null避免未知供应商拒绝。系统设置省略字段保留现值。执行开始固定强度并复用于分析、工具循环与复核，completion 转为 reasoning.effort；原90秒/预算/请求次数仍约束深度请求。不自动探测或降档，失败提示可改用服务商默认。元数据复用现有JSON，无数据库迁移；不暴露隐藏推理。
