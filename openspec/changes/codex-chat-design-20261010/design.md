# Design

## 参考与取舍

参考公开 Codex 桌面界面中的会话侧栏、紧凑标题、阅读列与统一输入区。公开界面描述来源：https://simonwillison.net/2026/feb/2/introducing-the-codex-app/ ，产品入口：https://openai.com/index/introducing-the-codex-app/ 。工具禁止读取当前 Codex 客户端；官方网页直接访问受限，故不声称与当前客户端逐像素一致。保留运维百晓生原创商标和蓝色焦点，辅助内容使用本项目真实能力。

## 视觉方案

颜色：阅读白 #ffffff、侧栏灰 #f6f6f6、墨色 #242424、次级灰 #737373、边界灰 #e6e6e6、品牌蓝 #315fff。标题使用系统中文字体的中等字重，正文使用系统无衬线 15px，代码/耗时用 ui-monospace。避免外部字体请求。

```text
浅灰侧栏 248px      紧凑标题                    执行 / 后台
品牌 / 收起        ─────────────────────────────────────
新建 / 查找                  用户问题灰色气泡 →
资源 / 文档 / 入门        助手正文、状态、来源、证据
最近对话                 同一阅读列，内部滚动
                         返回最新消息
设置 / 退出              [知识 / 复核                ]
                         [输入问题                    ]
                         [+  Agent  强度  模型      ↑/■]
```

记忆点是两种内容明确的阅读节奏：用户问题是右侧短气泡，助手以完整正文回答。去掉欢迎页定制推广块与模拟窗口栏；模板和文档通过直接入口可达。菜单保留已实现的用途说明、键盘与历史锁，不新建层层选项菜单。

## 交互与边界

会话搜索只过滤当前用户已有最近摘要，不请求模型或改写会话。侧栏折叠能再次展开；窄屏沿用导航抽屉，不卸载 Chat。输入高度随草稿变化，在有限高度内滚动；Enter/Shift+Enter与输入法语义保留。阅读旧消息时不强制跟随，返回最新按钮恢复跟随。状态、停止、独立复核发布门禁、目标确认、持久回读和只读恢复均沿用当前逻辑。全景回归发现done提前清空实时图谱，现与最终消息发布同步替换，保证实时到历史查看连续。所有辅助控件保持可见名称或准确 aria-label。

chat-design.css 在 workspace.css 后加载，使用 chat-workspace / chat-page 范围控制，portal 菜单保留原有样式。320px 与短屏在输入底部换行，目标确认展开仍限制高度。减少动效不引入额外动画。

## 验证

全量测试/构建、独立只读界面 fixture 的桌面/320px/短屏截图和键盘、现有流式与复核/目标浏览器回归、文档网站构建与检查。使用临时数据和本地模型夹具，不读日常模型凭据或调用真实 DTS。
