# Proposal

## Why

问答页有模拟窗口栏、双层入口、欢迎页推广卡片和输入框外的多个选项，阅读与输入被辅助内容分割。用户要求参考 Codex 客户端调整对话问答设计。

## What Changes

- 聊天专用浅灰侧栏，提供新建、查找最近对话、资源、文档和入门直接入口；精简顶部工具栏。
- 欢迎页用原创品牌、简短标题和问题示例，去掉大面积定制卡片。
- 用户问题右对齐灰色气泡，助手回答采用无卡片的正文列，保留真实状态、来源、复核和全景。
- 知识与复核开关统一放进输入框，保留 Agent、强度、附件与发送/停止；输入按草稿高度伸展，提供返回最新消息。
- 最终答复发布时同步替换实时全景，避免正在查看的弹窗在正文显示收敛期间关闭。
- 聊天专用样式覆盖，不调整后台页面的视觉系统。

## Capabilities

### New Capabilities

- `chat-design`: 简洁聊天工作空间、会话查找、连续阅读与统一输入。

### Modified Capabilities

无归档主规范变更。

## Impact

src/App.tsx、components/Chat.tsx、chat-design.css、浏览器验收与对应文档。无新依赖、API、数据库或运行时协议变更，不部署远程实例。
