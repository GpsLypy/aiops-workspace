# DTS 接入开发交接

本公开仓库提供通用只读 MCP 适配器，不包含 DTS 业务后端、生产凭据、任务数据或内部部署记录。接入自己的系统前阅读 [适配器说明](README.md)、[配置示例](.env.example)、[接入教程](../../docs/ops-onboarding.md)和[验证记录](../../docs/verification.md)。

## 接入边界

- 由部署者配置自己有权访问的状态接口、业务域、区域与任务范围。默认使用任务白名单，不使用通配符。
- 任务 ID 保持十进制字符串，避免 JavaScript 大整数精度损失；以适配器和测试定义的响应契约为准。
- MCP 默认仅监听 loopback，使用独立 Token；远程接入通过受控网络或严格校验主机密钥的 SSH 隧道。
- 平台工具策略、查询目标绑定、审批与适配器上游权限共同生效；授权范围不可由模型猜测或扩大。
- 状态新鲜度、人工暂停、引擎暂停和 HA 待命需按自己的上游协议核实，单个 paused 字段不足以证明故障。
- 本仓库测试使用本机受控模型和 MCP 夹具；不证明任何真实 DTS 系统可用或生产验收通过。

## 后续开发

先读根目录 `AGENTS.md`、`codemap.md`、`agent.md` 和相关目录地图。行为改动同步接口说明、测试与验证记录，再运行 `npm test`、`npm run build`、`npm run docs:build`、`npm run docs:check`。不要提交真实 `.env`、密钥、数据库、会话和验收报告。
